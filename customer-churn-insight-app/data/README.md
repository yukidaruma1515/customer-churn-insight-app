# Data

Kaggleの「Telco Customer Churn」CSVを `WA_Fn-UseC_-Telco-Customer-Churn.csv` という名前で配置してください。

必要カラム:

- customerID
- gender
- SeniorCitizen
- Partner
- Dependents
- tenure
- PhoneService
- MultipleLines
- InternetService
- OnlineSecurity
- OnlineBackup
- DeviceProtection
- TechSupport
- StreamingTV
- StreamingMovies
- Contract
- PaperlessBilling
- PaymentMethod
- MonthlyCharges
- TotalCharges
- Churn

CSVがない場合でも、アプリは同形式のサンプルデータを自動生成して動作します。
