# customer-churn-insight-app
Telco Customer Churnデータを用いて、顧客の解約傾向を分析・可視化し、機械学習で解約予測を行うアプリ

## WebアプリURL

Streamlitで公開したWebアプリはこちらです。

https://share.streamlit.io/yukidaruma1515/customer-churn-insight-app/main/customer-churn-insight-app/app.py

```bash
cd customer-churn-insight-app
streamlit run app.py
```
